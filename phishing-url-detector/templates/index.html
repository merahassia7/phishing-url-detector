A Propos du Projet
Ce projet combine quatre moteurs de detection:
1. XGBoost pour les features structurelles de l'URL.
2. SecureBERT pour le contexte semantique de l'URL.
3. Zero-Day heuristique pour les patterns emergents.
4. Analyse HTML optionnelle pour des signaux supplementaires.

Le module Batch permet d'analyser plusieurs URLs ligne par ligne.
L'historique affiche les URLs deja testees via l'interface.
